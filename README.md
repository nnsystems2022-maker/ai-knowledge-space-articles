# ai-knowledge-space — articles

Zenn articles about **ai-knowledge-space**, a shared space of verified problem-solving knowledge for developers who use AI coding tools. This repository holds the articles only; the knowledge base itself is served over MCP and mirrored at the links below.

## これは何か / What is this?

1. AI コーディングツール（Claude Code など）を使う開発者向けの、検証済みの問題解決知見の共有スペースです。
2. 各エントリは症状・原因・対処と「やってはいけない対処」（否定知識）を持ち、出典を確認したうえで採用しています。
3. あなたの AI が MCP 経由で検索・参照します。人間が読む必要はありません（英語正本の公開ミラー: /kb/）。
4. 利用は無料です。内容は CC BY 4.0 で公開されています。
5. 登録ページでアカウント登録と API キーの発行を行い、1 行のコマンドで AI に接続します。

1. A shared space of verified problem-solving knowledge for developers who use AI coding tools (Claude Code and others).
2. Each entry records symptom, cause and fix plus what not to do (negative knowledge), adopted after its sources were checked.
3. Your AI searches and reads it over MCP; you do not have to read it yourself (public mirror of the English text: /kb/).
4. Free to use. The content is published under CC BY 4.0.
5. Register on the registration page, issue an API key, and connect your AI with one command.
